# tmpl-ask — what is the ask, what do you need

Invoked when the user can't tell what you think you're doing, or when what you produced isn't usable.

## Shape — four lines, no more

| line | content |
|---|---|
| **Ask** | what I believe you asked for, in one sentence |
| **State** | what exists right now — done / half-done / not started |
| **Blocker** | the one thing stopping completion (or "none") |
| **Need** | the specific answer that unblocks me — a decision, a path, a yes/no |

## Rules

- **Never "shall I proceed?"** — that's not a blocker, that's hesitation. If nothing blocks you, say "none" and the work continues.
- **One need, not a menu.** If several things are unclear, name the one that gates the rest.
- No re-narrating history, no apology, no summary of what went wrong — the four lines only.
- If the honest answer is "I made this un-executable", say that in the Blocker line plainly.
