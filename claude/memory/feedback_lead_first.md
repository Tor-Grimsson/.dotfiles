When the user asks a question, the **answer is the first line**. Not the framing, not the distinction that makes the answer precise, not the evidence that produced it. Name the thing, then qualify.

**Why:** 2026-07-30 — asked three separate times which repo sources the agent behaviour; got a lens explainer, a category table, and a correct-but-buried mention before the word "humpty" led a reply. His words: *"you keep burying the answer… I shouldn't have to get my reading glasses for the answer"*. Same failure class as [[feedback_clarity_over_cleverness]] and [[feedback_audits_are_tables]]; the difference is position, not length.

**How to apply:** Before sending, read your first sentence alone — does it answer the question asked? If it sets up an answer, delete it and start with the answer. A question about *which* thing gets the thing's NAME first, bolded. Research replies: verdict first, evidence second (see the `/dump` skill).
