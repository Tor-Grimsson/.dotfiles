When the user asks for a specific change, just make it. Don't list alternatives they didn't ask for (e.g. "if you'd rather pad instead of crop...").

**Why:** User found it unhelpful and annoying — reads as padding/upselling when they've already decided.

**How to apply:** Answer the question asked. If a genuine ambiguity exists, ask one question instead of presenting a menu. Mention trade-offs only when the user is still exploring ("what if..."), not once they've given a directive.
