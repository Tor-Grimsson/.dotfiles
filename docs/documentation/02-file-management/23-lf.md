## Summary

lf ("list files") is ranger's design with the Python removed: one static Go binary, no runtime, no config required to work. Layout is miller columns adjusted by `ratios` — the same single knob [[02-yazi|yazi]] has.

## Why installed

Installed 2026-08-01 from the layout-mode survey. It offers no layout modes beyond ratios, so it was kept for a different reason: it is the one to reach for over SSH or on a machine where installing a runtime is not wanted.

## Most common use case

Browsing on a remote box where a single scp'd binary is the whole install.

## Biggest win

**Cold start.** No interpreter, no plugin load, no cache warm — it draws immediately. Custom commands are plain shell in `lfrc`, so extending it needs no plugin API.

## How to use

Config is repo-tracked at `lf/lfrc` (live via `~/.config/lf` → `~/.dotfiles/lf`). All eight options below were verified against `lf -doc`.

```
set mouse true          # off by default
set hidden true
set icons true
set drawbox true
set ignorecase true
set scrolloff 4
set previewer bat
set shell zsh
```

Colours come from `LS_COLORS`/ANSI, so [[09-productivity-desktop/08-kol-theme|kol-theme]] tints it with no per-app file.

## Future use

`cmd` definitions in `lfrc` are plain shell functions — the cheapest place to wire repo scripts (`clip-drop.sh`, `bucket`) into a file manager.
