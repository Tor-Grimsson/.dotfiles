# terminal — quick reference

Filter: `ref-terminal <word …>` · ghostty (daily) · kitty (mirror + stickies)

## ghostty

| keys        | does                                       |
|-------------|--------------------------------------------|
| cmd+← cmd+→ | line start / end (← = C-a ×2, passes tmux) |
| cmd+delete  | kill line back (C-u)                       |
| opt+delete  | delete word back                           |
| opt+← opt+→ | word back / forward                        |
| cmd+shift+, | reload config                              |

## kitty

| keys          | does                                    |
|---------------|-----------------------------------------|
| (same map)    | kitty.conf mirrors ghostty, 29/7/26     |
| shift+enter   | newline in Claude Code (ESC+CR)         |
| ctrl+shift+f5 | reload config in a running window       |
