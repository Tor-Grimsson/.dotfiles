# NAMING — the three-family system (agent reference)

Names are **picked from a bag, never invented**. Ask what kind of thing it is → use that family. Set 2026-07-28; user-facing copy: `docs/kol-agent-system/10-naming.md`.

| Family | Domain | Test |
|---|---|---|
| **Glass** | **State** — holds or shows context (storage, snapshots, lenses) | "What's inside the glass?" → `<noun>-glass` or a real glass word |
| **Ubu Roi** | **Actors** — persona, behavior stack, hooks, discipline | Is it a character/prop in the theater of enforcement? |
| **Alice** | **Motion** — init, traversal, sync, search journeys | Does it take you somewhere? |

**Assigned:** **`jabberwocky`** (the umbrella repo — the whole exported OS) · **`humpty-dumpty`** (the wall-sitter plugin: reuse doctrine + muzzle stepper; also the private parent folder `kol-humpty-dumpty`) · `memory-glass` (memory tool, public) · `kol-glass` (private lens instance) · **Ubu Roi** (published persona — NEVER "Grim" in public material).

**Seed bags (unassigned — proposals, not decisions; English words only, no heavy French):**
- Glass: `hourglass` (journaling) · `spyglass` (routing/search) · `weather-glass` (status/monitoring)
- Ubu/Shakespeare: palotins (subagents) · `king-ubu` · `nowhere` · `elsinore` · `dunsinane` · `birnam` · `yorick` · `arden`
- Alice: **`humpty-dumpty`** (chambered by the user — "a nice name for something") · `rabbit-hole` (boot/init) · `cheshire` (session-bridge) · `red-queen` (context trim) · `white-rabbit` (cron) · `wabe` · `red-king` · `boojum`
- Modernism: `readymade` · `merz` · `exquisite-corpse`

**Orthography:** compounds hyphenate (`memory-glass`, `white-rabbit`); canonical single names stay one word (`jabberwocky`, `cheshire`).

**Rules for agents:** the umbrella name is OPEN (glass bag, user's call). Never present a new name as decided — propose from the bag, flag it, wait. Working titles in private repos stay descriptive (`kol-agent-system`).
